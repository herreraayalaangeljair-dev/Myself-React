# Portafolio Personal

Sitio web personal y portafolio interactivo desarrollado con **React**, diseñado con una estética cinematográfica, minimalista y oscura para presentar mis proyectos y pasatiempos.

## Vista Previa de la Interfaz

[![Ver video de la interfaz](https://img.youtube.com/vi/prwbQeRqCMw/maxresdefault.jpg)](https://youtu.be/prwbQeRqCMw)

---

## Características de la Interfaz

- **Diseño Cinematográfico:** Estética oscura, tipografía elegante y un estilo visual minimalista.
- **Sección de Inicio:** Presentación personal orientada al desarrollo y la creación digital.
- **Proyectos:** Espacio dedicado a mostrar el software desarrollado con enlaces directos a GitHub.
- **Pasatiempos:** Un vistazo a intereses personales como la lectura (fantasía, terror y educación financiera) y el estudio de idiomas.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** React.js
- **Estilos:** Tailwind CSS
- **Hosting y Despliegue:** Firebase Hosting
- **Control de Versiones:** Git & GitHub
